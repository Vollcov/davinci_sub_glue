# davinci_sub_glue

Скрипт **Subtitle Glue** для DaVinci Resolve: читает сгенерированные субтитры на активном таймлайне и убирает пустые промежутки между ними, удлиняя каждый субтитр до начала следующего.

## Почему Text+, а не subtitle-дорожка

API Resolve не умеет:

- менять длительность уже лежащих subtitle-клипов;
- надёжно удалять их с таймлайна;
- ставить импортированный SRT в нужный кадр — `AppendToTimeline` **всегда дописывает SRT сразу после последнего старого субтитра**.

Поэтому скрипт:

1. Считывает клипы с subtitle-дорожки (`GetStart` / `GetEnd` / текст из `GetName`).
2. Растягивает конец каждого субтитра до старта следующего.
3. Ставит результат как **Text+** на новую видеодорожку в исходных таймкодах (`recordFrame` для Text+ работает).
4. Отключает или, если получится, удаляет исходную subtitle-дорожку.
5. Кладёт SRT-копию в бин Media Pool **Subtitle Glue** — её можно экспортировать вручную.

## Установка

Скопируйте `SubtitleGlue.py` в папку скриптов Resolve:

| ОС | Папка |
| --- | --- |
| Windows | `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\` |
| macOS | `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/` |
| Linux | `~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/` |

Перезапустите Resolve (или обновите список скриптов).

## Как пользоваться

1. Откройте проект и **активный таймлайн** с уже сгенерированными субтитрами (`Timeline > Create Subtitles from Audio`).
2. Меню: **Workspace → Scripts → Utility → SubtitleGlue**.
3. Выберите дорожку, зазор в кадрах и лимит удлинения.
4. Нажмите **Заполнить паузы**.

На таймлайне появится видеодорожка `… (без пауз)` с зелёными Text+ клипами без дыр между ними. Исходная subtitle-дорожка будет отключена, если стоит галочка **Скрыть исходную subtitle-дорожку**.

Параметры:

- **Оставить зазор, кадров** — сколько пустых кадров оставить между субтитрами. `0` склеивает их встык.
- **Макс. удлинение, сек** — потолок, на сколько можно растянуть один субтитр в паузу. `0` = без лимита.
- **Скрыть исходную subtitle-дорожку** — выключает старые субтитры, чтобы они не дублировали Text+.

Последний субтитр не удлиняется: закрываются только паузы *между* соседними репликами.

## Если нет окна настроек

В бесплатном Resolve начиная с 19.1 UIManager может быть недоступен. Тогда скрипт сразу обработает все непустые subtitle-дорожки с настройками по умолчанию. Результат пишется в **Workspace → Console**.

## Требования

- DaVinci Resolve 18+ (Free или Studio)
- Активный таймлайн с хотя бы двумя субтитрами на subtitle-дорожке
- Страница Edit (скрипт переключается на неё сам)

Работает с **отдельными subtitle-клипами** — так Resolve раскладывает результат *Create Subtitles from Audio*.
