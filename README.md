# davinci_sub_glue

Скрипт **Subtitle Glue** для DaVinci Resolve: читает сгенерированные субтитры на активном таймлайне и убирает пустые промежутки между ними, удлиняя каждый субтитр до начала следующего.

Resolve не даёт менять длительность готовых subtitle-клипов через API, поэтому скрипт:

1. Считывает клипы с subtitle-дорожки (`GetStart` / `GetEnd` / текст из `GetName`).
2. Растягивает конец каждого субтитра до старта следующего.
3. Собирает новый SRT, **сначала убирает старые клипы с дорожки**, и кладёт новый файл в начало таймлайна (иначе Resolve дописывает SRT в конец старых субтитров).

## Установка

Скопируйте `SubtitleGlue.py` в папку скриптов Resolve:

| ОС | Папка |
| --- | --- |
| Windows | `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\` |
| macOS | `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/` |
| Linux | `~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/` |

Перезапустите Resolve (или обновите список скриптов).

## Как пользоваться

1. Откройте проект и **активный таймлайн** с уже сгенерированными субтитрами (`Timeline > Create Subtitles from Audio` или импортированный SRT).
2. Меню: **Workspace → Scripts → Utility → SubtitleGlue**.
3. Выберите дорожку (или все), при необходимости задайте зазор в кадрах и лимит удлинения.
4. Нажмите **Заполнить паузы**.

Параметры:

- **Оставить зазор, кадров** — сколько пустых кадров оставить между субтитрами. `0` склеивает их встык.
- **Макс. удлинение, сек** — потолок, на сколько можно растянуть один субтитр в паузу. `0` = без лимита (закрывать паузу целиком).
- **Заменить исходную дорожку** — удалить старые клипы и положить новый SRT на ту же дорожку в начало таймлайна. Если снять галочку, появится новая дорожка `… (без пауз)`.

Последний субтитр не удлиняется: закрываются только паузы *между* соседними репликами.

## Если нет окна настроек

В бесплатном Resolve начиная с 19.1 UIManager может быть недоступен. Тогда скрипт сразу обработает все непустые subtitle-дорожки с настройками по умолчанию (зазор 0, без лимита, с заменой исходной дорожки). Результат пишется в **Workspace → Console**.

Если автоматический импорт SRT не сработает, файл всё равно сохранится во временной папке — его можно перетащить на subtitle-трек вручную. Копия импортированных SRT также появляется в бине Media Pool **Subtitle Glue**.

## Требования

- DaVinci Resolve 18+ (Free или Studio)
- Активный таймлайн с хотя бы двумя субтитрами на subtitle-дорожке

Скрипт не конвертирует субтитры в Text+. Стиль новой дорожки будет стандартным стилем импортированного SRT.

Работает с **отдельными subtitle-клипами** — так Resolve раскладывает результат *Create Subtitles from Audio*. Если на дорожке лежит один цельный импортированный SRT-файл, внутренние паузы через API не видны.
