# davinci_sub_glue

Скрипт **Remove gap sub** для DaVinci Resolve: читает сгенерированные субтитры на активном таймлайне и убирает пустые промежутки между ними, удлиняя каждый субтитр до начала следующего.

## Как это работает

API Resolve не умеет менять длительность уже лежащих subtitle-клипов. `AppendToTimeline` для SRT игнорирует `recordFrame` и **всегда дописывает новые субтитры сразу после последнего старого**.

Тот же приём, что в скрипте орфографии: не импортировать SRT на текущий таймлайн, а пройти через формат Resolve `.drt`.

1. Экспортирует активный таймлайн в `.drt`.
2. На **той же** subtitle-дорожке заменяет длительности клипов — старые гэпы исчезают, стартовый кадр не двигается.
3. Если субтитр заканчивается на частицу **«не»**, она переносится в начало следующего. Субтитр A укорачивается с конца, субтитр B удлиняется с начала на те же кадры — сумма длительностей пары не меняется.
4. Импортирует результат как **новый таймлайн** `… (без пауз)`.
5. Исходный таймлайн не меняется и остаётся запасной копией.

## Установка

Скопируйте `Remove gap sub.py` в папку скриптов Resolve:

| ОС | Папка |
| --- | --- |
| Windows | `%APPDATA%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\` |
| macOS | `~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/` |
| Linux | `~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/` |

Если там лежит старый `SubtitleGlue.py`, удалите его, чтобы в меню не было двух скриптов.

Перезапустите Resolve (или обновите список скриптов).

## Как пользоваться

1. Откройте проект и **активный таймлайн** с уже сгенерированными субтитрами (`Timeline > Create Subtitles from Audio`).
2. Меню: **Workspace → Scripts → Utility → Remove gap sub**.
3. Выберите дорожку, зазор в кадрах и лимит удлинения.
4. Нажмите **Заполнить паузы**.

Resolve переключится на новый таймлайн `… (без пауз)`. Видео и звук те же. На той же subtitle-дорожке уже новые клипы без пауз на исходных таймкодах. Исходный таймлайн остаётся запасной копией со старыми субтитрами.

Параметры:

- **Оставить зазор, кадров** — сколько пустых кадров оставить между субтитрами. `0` склеивает их встык.
- **Макс. удлинение, сек** — потолок, на сколько можно растянуть один субтитр в паузу. `0` = без лимита.

Последний субтитр не удлиняется: закрываются только паузы *между* соседними репликами. Частица «не» в конце субтитра переносится к следующей реплике.

## Если нет окна настроек

В бесплатном Resolve начиная с 19.1 UIManager может быть недоступен. Тогда скрипт сразу обработает все непустые subtitle-дорожки с настройками по умолчанию. Результат пишется в **Workspace → Console**.

## Требования

- DaVinci Resolve 18+ (Free или Studio) с экспортом таймлайна в `.drt`
- Активный таймлайн с хотя бы двумя субтитрами на subtitle-дорожке
- Страница Edit (скрипт переключается на неё сам)

Работает с **отдельными subtitle-клипами** — так Resolve раскладывает результат *Create Subtitles from Audio*.
